# Manual checklist

- [ ] Assemble debug/release
- [ ] Swipe up opens drawer without “keeps stopping”
- [ ] Auto-keyboard on/off both safe
- [ ] Reorder home apps; neighbors shift; order persists after relaunch
- [ ] Widgets: pin (allow bind if prompted); picker shows a check on pinned widgets
- [ ] Widgets header: the screen opens with no top bar; a short bar marks a strip under the status bar. Drag down on the strip: the header (title, Add widget, "Tap and hold a widget to move, resize or remove it") follows the finger and springs open past half or on a flick, back shut otherwise; tap the strip: it springs open. A pull on the widgets themselves (on a button, a list widget, an empty spot) never opens it, every time. Drag the header up, scroll the widgets, tap beside them or press Back: it closes. Fast and Slow animation speed change how quickly it springs
- [ ] Widgets with none pinned: the header is already out with Add widget; open the picker and close it without adding: the header is back; add one widget: the header leaves by itself
- [ ] Widgets customize (tap and hold): hold a widget without moving: a haptic tick, the widget rises with an outline, the others dim, cells are outlined, an edit bar slides up ("Customize <widget>", "Drag the widget to move it", Width and Height with − and + buttons, Settings when the widget has a configure screen, Remove, Done) and the grid does not shift; nothing appears on the widget itself (no corner dot); a widget low on the screen scrolls clear of the bar. Width/Height +/− change the size one cell at a time; a button is disabled at one cell, at the grid edge, when a neighbour is in the way, or for a direction the widget does not allow; a widget that cannot be resized says so. Drag the widget (the same touch or a new one): the bar steps aside, the landing cell is highlighted, it lands in the nearest free cell. While a widget is picked, tapping another one picks it instead of opening its app. Remove asks to confirm. Done, a tap beside the widgets and Back each put the widget down
- [ ] Widgets with TalkBack: each widget offers Customize in its actions; a picked widget offers Make wider/narrower/taller/shorter (only the allowed directions) and Move left/right/up/down (blocked by a neighbour or the grid edge: nothing happens); "Show widget options" (the bar under the status bar) opens the header
- [ ] Widgets speed (release build, a few pinned widgets including a heavy one such as weather or calendar): wait two seconds after the launcher starts, then open Widgets: every widget is already drawn in the first frame of the slide (no tiles, no pop-in); leave and reopen at once and again a minute later: same; pin a new widget: it fades in over a tile within a moment; widgets keep updating (a clock widget ticks) after several visits and after the screen was off; on Android 11 or earlier the widgets still appear
- [ ] Screen time (Settings > Home screen > Screen time): the section holds Show on Home, Show in app library, Usage access and the size slider. With usage access not granted, switching Show on Home on opens the system screen; back in Settings the Usage access row says Allowed; the app library then shows today's usage after each app's name (`1h 5m`, `12m`, `<1m`; nothing for an app not used today), none for pinned shortcuts or Private Space apps; Show in app library off (or Show on Home off, which disables that row) removes the figures; the Home total equals the sum of the per-app figures; with Show on Home off no usage is queried (no `ScreenTimeSource` log lines)
- [ ] App drawer with auto-keyboard on: the drawer slides in with no hitch and the keyboard opens when the panel has stopped, at Fast, Standard and Slow speed
- [ ] Animation speed Slow and Fast: switches, buttons, list items, the picker, the widget glide and the edit bar also change speed, not only the panels
- [ ] Home: long-press empty space opens app picker; tapping a chip removes the app immediately
- [ ] Settings: swipe-down notifications toggle; grant notification listener if prompted
- [ ] Swipe down opens in-app notification list when toggle is on; list matches shade after listener grant
- [ ] Settings icons: in every group the leading icons and the switches or chevrons line up row after row, including rows whose subtitle wraps to two or three lines (they sit in the middle of the row, not on the title line); slider and choice rows keep the icon next to the title; the info and gear icons in the header end on the same edge as the switches and arrows below; rows that open Android's own settings (default launcher, display, wallpaper, usage access, every permission) show an open-in-new arrow, rows that open a picker or dialog (font, swipe left/right) a chevron; no two rows in one group show the same icon
- [ ] App library: the search field has a search icon at the start and a clear (x) button while there is text, like Settings; the gear at the right ends on the same edge as the app names' left margin
- [ ] Widgets edit bar: the button that opens the widget's own settings shows a gear
- [ ] Notifications and Summary without notification access: both panels say why they are empty and offer Grant notification access; allow it in system Settings, press Back: the panel fills in without being reopened
- [ ] Notifications and Summary look alike: same title size and place as Notes and Widgets, cards line up with the title, an app with several notifications shows a count badge, and a card's tint only shows while it is being swiped away (either direction)
- [ ] Notifications with TalkBack: each card offers Dismiss in its actions; an app with several notifications reads "Collapsed, double tap to show all" and then "Expanded"; the count badge is read as "3 notifications"; the panel titles, Settings group and section labels, app library letters, Notes' Completed label and the widget picker's title and app names are headings
- [ ] Notes and Settings with the keyboard up: the last note, and the last Settings search result, can be scrolled above the keyboard; the Undo snackbar shows above it
- [ ] Home app picker (long-press empty Home): each chosen app is a chip whose whole surface removes it; with TalkBack, an app already on Home reads "On Home" and is not offered as a button, and once Home is full no row is
- [ ] Home: pin 6–10 apps; toggle clock/date in Settings and return — list count stays
- [ ] Settings search filters groups; back swipe leaves Settings
- [ ] Assigned left/right swipe panels enter from the opposite edge and pop on the same axis
- [ ] Notes: add; swipe left shows red arrow and deletes; complete/reminder; screen back swipe does not steal delete
- [ ] Settings: clock size, section weight, section order, show apps
- [ ] Lint + unit tests green
