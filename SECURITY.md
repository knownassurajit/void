## Reporting a Vulnerability

If you discover a security vulnerability in VOID Launcher:
- Email security details directly to the maintainers before disclosing publicly.
- Include app version, Android SDK level, device details, and reproduction steps.
- Expect an acknowledgement within 48 hours.
